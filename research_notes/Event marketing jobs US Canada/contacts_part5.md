# Named contacts for event marketing roles, rows 48 to 56 (US healthcare and life sciences)

Scope: hiring manager, direct manager and key introduction at each of 9 companies. Research date 21 Oct 2026. WebSearch only, since WebFetch was blocked. Standard-mode search almost never returned LinkedIn profiles, so extended mode was used for name discovery.

**Coverage warning:** the web search budget for the turn (200 calls, shared by every agent running in parallel) ran out at the start of row 53. Rows 48 to 52 are researched. Row 53 (Impiricus) has postings but no names. Rows 54 to 56 (GeneDx, Artera, Fortrea) were never searched. Every row has a line in `contacts_part5.jsonl`, and the unresearched rows read "not found (target: ...)".
